iOS and iPadOS uploads must target iOS 13 or later

When
2026-09-09
Status
In effect
Platform
App Store
Who
iOS and iPadOS apps uploaded to App Store Connect
What happens
Blocks new releases. iOS and iPadOS apps uploaded to App Store Connect must target iOS 13 or later.

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo with a config plugin override: Set ios.deploymentTarget to 13.0 or later in expo-build-properties, or remove it.
  • Expo (Continuous Native Generation): Upgrade to an Expo SDK whose default iOS deployment target is 13.0 or later (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Xcode (native iOS): Set IPHONEOS_DEPLOYMENT_TARGET to 13.0 or later in the Xcode project and the Podfile platform.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Xcode (native iOS): Set IPHONEOS_DEPLOYMENT_TARGET to 13.0 or later in the Xcode project and the Podfile platform.
