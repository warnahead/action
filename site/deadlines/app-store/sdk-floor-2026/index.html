Uploads must be built with Xcode 26 and the 26 SDKs

When
2026-04-28
Status
In effect
Platform
App Store
Who
Apps uploaded to App Store Connect (iOS, iPadOS, tvOS, visionOS and watchOS)
What happens
Blocks new releases. Apps uploaded to App Store Connect must be built with Xcode 26 or later using an SDK for iOS 26, iPadOS 26, tvOS 26, visionOS 26, or watchOS 26.

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • EAS Build: Use an EAS Build image with Xcode 26 or later (table eas-images), or remove the image to get the SDK default.
  • Expo (Continuous Native Generation): Upgrade to an Expo SDK whose default EAS image has Xcode 26 or later (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Xcode (native iOS): Build and upload with Xcode 26 or later.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Xcode (native iOS): Build and upload with Xcode 26 or later.

Any stack

Wherever the project or its CI uses it.

  • GitHub Actions workflows: Build on a macOS runner with Xcode 26 or later and select it (table gha-runner-xcode).
