Actions declaring node20 now run on Node 24

When
2026-09-23
Status
In effect
Platform
GitHub Actions
Who
JavaScript actions whose action.yml declares runs.using node20, on GitHub-hosted runners
What happens
Warning only. Node 20 is no longer available on GitHub Actions runners. Runners now use Node 24 for JavaScript actions.

How to fix

Any stack

Wherever the project or its CI uses it.

  • GitHub Actions workflows: Upgrade to a release of the action that declares node24 (table action-runtimes), and check the job still passes on Node 24.

Sources

  1. https://github.blog/changelog/2026-09-23-node-20-is-no-longer-available-in-github-actions (primary source, retrieved 2026-11-18)

    This is the final notification that Node 20 is no longer available on GitHub Actions runners. Runners now use Node 24 for JavaScript actions.

  2. https://github.com/actions/runner/blob/main/src/Runner.Worker/Handlers/HandlerFactory.cs (primary source, retrieved 2026-11-18)

    Keep accepting legacy action manifests, but execute all JavaScript actions using node24.
