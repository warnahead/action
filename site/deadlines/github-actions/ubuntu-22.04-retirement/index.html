Ubuntu 22.04 runner images are retired on April 17, 2027

When
2027-04-17
Status
Announced
Platform
GitHub Actions
Who
GitHub-hosted jobs on ubuntu-22.04 or ubuntu-22.04-arm (brownouts fail some jobs before the retirement)
What happens
Breaks CI. Deprecation will begin on September 17th, 2026 and the images will be fully unsupported by April 17th, 2027.

How to fix

Any stack

Wherever the project or its CI uses it.

  • GitHub Actions workflows: Move ubuntu-22.04 jobs to ubuntu-24.04, ubuntu-26.04 or ubuntu-latest, and ubuntu-22.04-arm jobs to ubuntu-24.04-arm or ubuntu-26.04-arm.

Sources

  1. https://github.com/actions/runner-images/issues/14254 (primary source, retrieved 2026-11-18)

    Deprecation: September 17th, 2026 Retirement: April 17th, 2027

  2. https://github.com/actions/runner-images/issues/14254 (primary source, retrieved 2026-11-18)
