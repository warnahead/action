macOS 14 runner images are retired

When
2026-11-02
Status
In effect
Platform
GitHub Actions
Who
GitHub-hosted jobs on macos-14, macos-14-large or macos-14-xlarge
What happens
Breaks CI. GitHub Actions will fully retire all macOS 14 images on November 2, 2026.

How to fix

Any stack

Wherever the project or its CI uses it.

  • GitHub Actions workflows: Move these jobs to macos-latest, macos-15 or macos-26.
