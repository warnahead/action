ubuntu-latest moves to Ubuntu 26.04

When
2026-10-19
Status
In effect
Platform
GitHub Actions
Who
GitHub-hosted x64 jobs on ubuntu-latest
What happens
Warning only. ubuntu-latest moves from Ubuntu 24.04 to Ubuntu 26.04: This change will be rolled out over a period of several weeks beginning October 19, 2026. We plan to complete the migration by November 19, 2026.

How to fix

Any stack

Wherever the project or its CI uses it.

  • GitHub Actions workflows: If a job fails on Ubuntu 26.04, pin ubuntu-24.04 while you fix it; use ubuntu-26.04 to test the new image explicitly.
