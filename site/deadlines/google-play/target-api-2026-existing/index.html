Existing apps must target API 35 to stay available to new users

When
2026-08-31
Status
In effect
Platform
Google Play
Who
Android phone and tablet apps already published on Google Play (Wear OS needs API 34, Android TV API 33, Android XR API 34, Android Automotive OS API 32)
What happens
Hides the app from users. Existing apps must target Android 15 (API level 35) or higher to remain available to new users on devices running Android OS higher than your app's target API level.
Extension
Until 2026-11-01: On request in Play Console

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo with a config plugin override: Set android.targetSdkVersion to 35 or higher in expo-build-properties (36 to publish updates), or remove it.
  • Expo (Continuous Native Generation): Upgrade to an Expo SDK whose default targetSdk is 35 or higher (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Set targetSdk = 35 or higher where the project defines it (36 to publish updates).

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Set targetSdk = 35 or higher where the project defines it (36 to publish updates).
