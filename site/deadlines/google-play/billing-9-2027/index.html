New apps and updates must use Play Billing Library 9 or later

When
2027-08-31
Status
Announced
Platform
Google Play
Who
Android apps on Google Play that use the Play Billing Library
What happens
Blocks new releases. Existing apps still work, but new apps and updates must use supported versions: Play Billing Library 9 or later from August 31, 2027.
Extension
Until 2027-11-01: On request in Play Console

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • npm packages: Upgrade the in-app purchase package to a release that uses Play Billing Library 9 or later (table billing-versions).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Set com.android.billingclient:billing (or billing-ktx) to 9.0.0 or later.
  • npm packages: Upgrade the in-app purchase package to a release that uses Play Billing Library 9 or later (table billing-versions).

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Set com.android.billingclient:billing (or billing-ktx) to 9.0.0 or later.
