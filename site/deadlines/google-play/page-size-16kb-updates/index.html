All deadlines

App updates must support 16 KB memory pages

When
2027-02-01
Status
Announced
Platform
Google Play
Who
Android phone and tablet apps submitted to Google Play that target API 35 or higher
What happens
Blocks new releases. App updates that target Android 15 (API level 35) or higher and do not support 16 KB memory page sizes on 64-bit devices can't be released on Google Play.

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo (Continuous Native Generation): Update the dependencies with native code to versions aligned to 16 KB, then check the release build with warnahead --check-binaries.

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • React Native: Upgrade to React Native 0.77 or higher (for Expo, an SDK that has it) and update libraries with native code.
  • Gradle (native Android): Build native code with NDK 28 or higher and Android Gradle plugin 8.5.1 or higher, update prebuilt libraries, then check the release build with warnahead --check-binaries.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Build native code with NDK 28 or higher and Android Gradle plugin 8.5.1 or higher, update prebuilt libraries, then check the release build with warnahead --check-binaries.
