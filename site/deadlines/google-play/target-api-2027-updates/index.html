New apps and updates must target API 37

When
2027-08 (month)
Status
Announced
Platform
Google Play
Who
Android phone and tablet apps submitted to Google Play
What happens
Blocks new releases. New and updated apps are required to target API level 37 (Android 17): August 2027, no day published yet.

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo with a config plugin override: Before August 2027, set android.targetSdkVersion to 37 in expo-build-properties, or remove it if the Expo SDK default is 37 (table expo-sdk-defaults).
  • Expo (Continuous Native Generation): Before August 2027, upgrade to an Expo SDK whose default targetSdk is 37 (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Before August 2027, set targetSdk = 37 where the project defines it.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Before August 2027, set targetSdk = 37 where the project defines it.
