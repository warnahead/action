New apps and updates expected to need API 37

When
Aug 2027
Status
Expected, not announced
Platform
Google Play
Who
Android phone and tablet apps published on Google Play
What happens
Blocks new releases. Expected, not announced: new apps and app updates must target Android 17 (API level 37) or higher to be submitted to Google Play.
Why expected
Google Play raised the target API level for new apps and updates on August 31 in 2025 (API 35) and 2026 (API 36); no API 37 requirement was announced on 2026-11-11. (confidence: medium)

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo with a config plugin override: Plan to set android.targetSdkVersion to 37 in expo-build-properties, or remove it, once Google announces the requirement.
  • Expo (Continuous Native Generation): Plan an upgrade to an Expo SDK whose default targetSdk is 37 (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Plan to set targetSdk = 37 where the project defines it.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Plan to set targetSdk = 37 where the project defines it.
