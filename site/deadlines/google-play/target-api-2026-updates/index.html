New apps and updates must target API 36

When
2026-08-31
Status
In effect
Platform
Google Play
Who
Android phone and tablet apps published on Google Play (Wear OS and Android Automotive OS need API 35, Android TV and Android XR need API 34)
What happens
Blocks new releases. New apps and app updates must target Android 16 (API level 36) or higher to be submitted to Google Play.
Extension
Until 2026-11-01: On request in Play Console

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo with a config plugin override: Set android.targetSdkVersion to 36 in expo-build-properties, or remove it.
  • Expo (Continuous Native Generation): Upgrade to an Expo SDK whose default targetSdk is 36 (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Set targetSdk = 36 where the project defines it.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Set targetSdk = 36 where the project defines it.
