All deadlines

New Android XR apps and updates must target API 34

When
2026-08-31
Status
In effect
Platform
Google Play
Who
Android XR apps submitted to Google Play whose manifest requires the Android XR feature
What happens
Blocks new releases. New Android XR apps and app updates must target Android 14 (API level 34) or higher to be submitted to Google Play.
Extension
Until 2026-11-01: On request in Play Console

How to fix

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • Gradle (native Android): Set targetSdk = 34 or higher in the Android XR app module.

Native Android and iOS

For an app built with Gradle or Xcode alone.

  • Gradle (native Android): Set targetSdk = 34 or higher in the Android XR app module.
