Eclipse Temurin 26 reached end of availability

When
2026-09 (month)
Status
In effect
Platform
Runtimes
Who
Projects whose Java is Eclipse Temurin 26 (actions/setup-java with distribution temurin, a Gradle toolchain with vendor ADOPTIUM, a temurin .java-version, or an eclipse-temurin Docker image)
What happens
Warning only. End of availability since September 2026 on the Eclipse Temurin support page: no more Temurin updates for Java 26.

How to fix

Any stack

Wherever the project or its CI uses it.

  • java: Move to the next Eclipse Temurin feature release or to a supported LTS release.
