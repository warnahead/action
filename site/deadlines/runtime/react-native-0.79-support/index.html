React Native 0.79 is unsupported

When
2025-10-08
Status
In effect
Platform
Runtimes
Who
Projects that resolve react-native 0.79.x
What happens
Warning only. Unsupported since 2025-10-08: no new releases are to be expected.

How to fix

Expo

For an Expo app whose android and ios folders are generated by prebuild.

  • Expo (Continuous Native Generation): Upgrade to an Expo SDK that uses react-native 0.88 or later (table expo-sdk-defaults).

Bare React Native

For a React Native app that keeps its android and ios folders in the repository, Expo modules or not. Native changes go into those folders.

  • React Native: Upgrade to react-native 0.88 or later.
